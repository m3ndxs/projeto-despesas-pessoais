# 📊 App de Despesas Pessoais

Aplicativo mobile desenvolvido em **Flutter** com o objetivo de ajudar usuários a **registrar, visualizar e gerenciar despesas pessoais** de forma simples e intuitiva.

Este projeto foi construído durante o módulo **“Construindo um App Real – Despesas Pessoais”** do curso de Flutter & Dart na Udemy, com foco em aplicar conceitos fundamentais do desenvolvimento mobile na prática.

---

## 🚀 Funcionalidades

- ➕ Adicionar novas despesas  
- ❌ Remover despesas  
- 📊 **Gráfico de Pizza** para visualização dos gastos mensais  
- 📈 **Gráfico de Barras** para visualização dos gastos semanais  
- 🗓️ Seleção de data com **DatePicker**  
- 📝 Formulário com validação de campos  
- 📱 Interface responsiva  

---

## 🧠 Conceitos e Tecnologias Utilizadas

- **Flutter & Dart**
- Criação e composição de **Widgets**
- **StatefulWidget** e gerenciamento de estado
- Modelagem de dados (`Transaction`)
- **ListView** e listas personalizadas
- Scroll e ajuste dinâmico de layout
- **ThemeData** e estilização global
- Fontes personalizadas
- Exibição de **Modal Bottom Sheet**
- Validação de formulários
- Gráficos customizados (**Chart Widget**)

## 🛠️ Como Executar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/nome-do-repositorio.git
```
2. Acesse a pasta do projeto:
```bash
cd projeto-despesas-pessoais
```
3. Instale as dependências:
```bash
flutter pub get
```
4. Execute o aplicativo:
```bash
flutter run
```
